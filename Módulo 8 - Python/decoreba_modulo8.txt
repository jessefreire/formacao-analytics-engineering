OPERADORES
--------------------------------------------
Aritmeticos: + - * / // % **
Atribuicao:   = += -= *= /= %=
Comparacao:   > < == != >= <=
Logicos:      and or not
Identidade:   is / is not (mesmo objeto memoria)
Associacao:   in / not in (pertence a sequencia)

>> PEGADINHA: = e ATRIBUICAO, == e COMPARACAO

LISTAS
--------------------------------------------
- Indices comecam em ZERO
- var.append(x)    -> adiciona ao final
- var.remove(x)    -> remove 1a ocorrencia (erro se nao existir)
- var.insert(i, x) -> insere no indice i
- var.pop(i)       -> remove do indice i (ou ultimo)
- var.index(x)     -> indice da 1a ocorrencia
- var.count(x)     -> conta ocorrencas
- var.sort(reverse=True) -> ordena decrescente

DICIONARIOS
--------------------------------------------
- Chave: valor (chaves UNICAS; reescreve se repetir)
- dic['chave']       -> acessa valor
- dic['nova'] = v    -> cria/atualiza
- dic.keys()         -> chaves
- dic.values()        -> valores
- dic.items()         -> pares (chave, valor)
- dic.pop('chave')   -> remove chave

MACHINE LEARNING - TREINO/TESTE

from sklearn.model_selection import train_test_split

MATRIZ DE CONFUSAO
--------------------------------------------
               Predito
              0      1
Real  0      TN     FP
      1      FN     TP

TP = Verdadeiro Positivo (acertou positivo)
TN = Verdadeiro Negativo (acertou negativo)
FP = Falso Positivo (erro tipo I)
FN = Falso Negativo (erro tipo II)

Metricas:
  Acuracia  = (TP + TN) / Total
  Precisao  = TP / (TP + FP)      -> qualidade da previsao positiva
  Revocacao = TP / (TP + FN)      -> capacidade de identificar positivos
  F1-Score  = 2 * (Prec * Revoc) / (Prec + Revoc)  -> media harmonica
